# deck-builder — カードでデッキを作って点を競う

財宝・王国カードを買い集めて点を競う、1台を回して遊ぶデッキ構築の試作

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/deck-builder/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

2〜4人、1台の端末を回して遊ぶデッキ構築（ドミニオン風）の試作。CPU を入れられる。

- はじめに人数と、席ごとに「人」か「CPU（よわい・ふつう・つよい・さいきょう）」を選ぶ（既定は1人目が人、ほかは CPU ふつう）。全員 CPU にすると観戦でき、観戦の速さ（ふつう・速い）も選べる。
- 遊ぶカードの組（王国カード 10 種）を選ぶ。組は 3 通りの選び方。
  - おすすめ: 拡張ごとに用意した組から選ぶ。
  - おまかせ: 遊ぶ拡張にチェックを付けて、ランダムに 10 種（引き直しできる）。
  - 自分で選ぶ: 好きな 10 種を選ぶ。
  - 選んだ人数・席・組は次に開いたときも覚えている。
- 手番の初めは「◯さんに渡してください」の画面。押すと自分の手札が見える（人が1人だけ、または CPU の番のときは出ない）。
- CPU の番は、手札やサプライを押しても何も起きない。CPU が 1 手ずつ勝手に進める（少し間をあけて、場と買った札が見える）。「つよい」「さいきょう」は最初の手番だけ少し考える時間がある。
- アクションフェイズ：手札のアクションカードを使う（購入フェイズへ進むまで何枚でも）。
- 購入フェイズ：財宝を出して（まとめて出すボタンあり）、サプライからカードを買う。
- 手番を終えると、場と手札をすべて捨てて 5 枚引き、次の人に渡る。
- アタックを使うと、ほかの人が捨てる・災いを得るなどの問いが挟まる（「水濠」などのリアクションを持っていれば見せて防げる・受け止められる）。答える人が今見ている人と違うときは、先に渡す画面をはさむ。
- イベント・プロジェクト・ランドマーク・習性などは「イベントなど」の列に並ぶ。おすすめの組のいくつかは組み合わせて選ばれ、おまかせ・自分で選ぶでも 0〜2 枚選べる。
- 拡張によっては購入フェイズのあとに「夜のフェイズ」（夜行の札を使う）がある手番、村人・財源・借金・勝利点トークンなどの印がある。
- 領地の山が空になるか、サプライの山が 3 つ空になったら、その手番の終わりに終了。点の多い人が勝ち。
- 拡張は「基本」「基本（初版）」「陰謀」「陰謀（初版）」「海辺」「海辺（初版）」「繁栄」「繁栄（初版）」「異郷」「異郷（初版）」「収穫祭＆ギルド」「収穫祭＆ギルド（初版）」「錬金術」「暗黒時代」「冒険」「帝国」「夜想曲」「ルネサンス」「移動動物園」「プロモ」「同盟」「略奪」「旭日」の 23 つ、王国カードは合わせて 498 種。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

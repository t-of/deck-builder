# deck-builder — カードでデッキを作って点を競う

財宝・王国カードを買い集めて点を競う、1台を回して遊ぶデッキ構築の試作

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/deck-builder/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

2〜4人、1台の端末を回して遊ぶデッキ構築（ドミニオン風）の試作。CPU はいない。

- はじめに人数と、遊ぶカードの組（王国カード 10 種）を選ぶ。組は 3 通りの選び方。
  - おすすめ: 拡張ごとに用意した組から選ぶ。
  - おまかせ: 遊ぶ拡張にチェックを付けて、ランダムに 10 種（引き直しできる）。
  - 自分で選ぶ: 好きな 10 種を選ぶ。
  - 選んだ人数・組は次に開いたときも覚えている。
- 手番の初めは「◯さんに渡してください」の画面。押すと自分の手札が見える。
- アクションフェイズ：手札のアクションカードを使う（購入フェイズへ進むまで何枚でも）。
- 購入フェイズ：財宝を出して（まとめて出すボタンあり）、サプライからカードを買う。
- 手番を終えると、場と手札をすべて捨てて 5 枚引き、次の人に渡る。
- アタックを使うと、ほかの人が捨てる・災いを得るなどの問いが挟まる（「水濠」などのリアクションを持っていれば見せて防げる・受け止められる）。答える人が今見ている人と違うときは、先に渡す画面をはさむ。
- 領地の山が空になるか、サプライの山が 3 つ空になったら、その手番の終わりに終了。点の多い人が勝ち。
- 拡張は「基本」「基本（初版）」「陰謀」「陰謀（初版）」の 4 つ、王国カードは合わせて 64 種。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
